# 🧽 비키니시티 분실물 탐정단 & 가상 중고 거래소

> 중고 거래 사이트(`http://localhost:4000`)를 실시간으로 탐색하여 잃어버린 물건을 자동으로 찾고 알림을 주는 스마트 분실물 추적 서비스(`http://localhost:3000`)입니다.

---

## 💡 주요 기능

1. **가상 중고 거래 웹사이트 (`public_market`)**
   - 중고 게시글 조회, 카테고리 필터, 판매글 작성 및 게시글 직접 삭제(`DELETE`) 기능
2. **스폰지밥 분실물 자동 추적 사이트 (`public_finder`)**
   - 분실물 품목 및 키워드 등록
   - 실시간 스캐너 ON/OFF 스위치 및 2.5초 간격 크롤링/폴링
   - 일치 중고물품 발견 시 **🚨 실시간 알림 팝업 + 효과음 경보**

---

## 🛠️ 실행 방법

```bash
# 1. 패키지 설치
npm install

# 2. 서버 실행
npm start
```

- **가상 중고 거래 사이트**: http://localhost:4000
- **분실물 추적 사이트**: http://localhost:3000
